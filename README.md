## Questionário teórico - Git e GitHub

### 1. Qual é a diferença entre Working Directory, Staging Area e Repository?
- **Working Directory:** Diretório local onde você cria e edita os arquivos.
- **Staging Area:** Área intermediária onde seleciona alterações (`git add`).
- **Repository:** Banco de dados do Git (`.git`) que armazena o histórico dos commits.

### 2. Qual é a diferença entre git commit e git push?
- **git commit:** Salva as alterações da Staging Area para o repositório local.
- **git push:** Envia os commits do repositório local para o GitHub.

### 3. É possível realizar vários commits antes de executar um git push? Explique.
**Sim.** Você pode acumular vários commits locais e enviar todos de uma vez com o `git push`.

### 4. Por que é interessante realizar commits pequenos e descritivos?
Facilita o rastreamento de bugs, revisões de código e reversão de partes específicas.

### 5. O que acontece com os commits locais quando ainda não executamos o git push?
Ficam salvos apenas na máquina local.

### 6. Como verificar, pelo GitHub, se os commits foram enviados corretamente?
Acessando a página do repositório e verificando a aba/histórico de **commits**.
